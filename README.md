# АлтГПУ Расписание — выпуски

Здесь лежат готовые APK приложения «АлтГПУ Расписание» и «АлтГПУ β» — во вложениях к [выпускам](../../releases).

Это запасная копия: приложение проверяет обновления на сайте https://altgpu-schedule.vercel.app, а если он недоступен — здесь (version.json, version-exp.json).

Код приложения в этом репозитории не хранится.
